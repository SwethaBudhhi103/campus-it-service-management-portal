# campus-it-service-management-portal
A ServiceNow-based campus IT service management project for handling IT requests, incidents, assignment, SLAs, and notifications.

## 1. Project Overview
A ServiceNow-based application for managing campus IT requests and incidents.

## 2. Problem Statement
Students and faculty need a centralized platform to report IT issues, submit service requests, track progress, and receive resolution updates.

## 3. Objectives
- Centralize campus IT support.
- Track incidents and service requests.
- Route tickets to the correct IT team.
- Monitor response and resolution SLAs.
- Notify requesters about ticket updates.
- Provide reports and dashboards.

## 4. Users and Roles
- Student — submits requests and reports incidents.
- Faculty/Staff — requests IT services.
- IT Agent — investigates and resolves tickets.
- IT Manager/Admin — manages configuration, permissions, and reporting.

## 5. Project Scope
### In Scope
- Incident and request management
- Assignment groups and ticket routing
- Priority and SLA management
- Flow Designer automation
- Notifications, reports, and dashboards
- Role-based access control
### Out of Scope
- Live college Wi-Fi integration
- Live student information system integration
- Real-time hardware monitoring
- Full production deployment

## 6. IT Support Groups
- Service Desk L1
- Network Team
- Application Team
- Hardware Team

## 7. Technology Stack
- Platform: ServiceNow
- Automation: Flow Designer
- Configuration: Tables, Forms, UI Policies, Client Scripts, Business Rules
- Security: Roles and Access Control Lists (ACLs)
- Data Import: Import Sets and Transform Maps
- Version Control and Documentation: GitHub

## 8. Project Workflow
Requester → Submit Request/Incident → Assign Group → Agent Works on Ticket → SLA Tracking → Resolution → Notification → Closure

## 9. Example Scenario
A student reports a college Wi-Fi access issue. The ticket is routed to the Network Team, investigated by an IT agent, and resolved. The student receives a resolution notification.
